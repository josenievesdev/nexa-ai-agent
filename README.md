# NEXA AI

Agente inteligente empresarial basado en modelos locales de IA.

NEXA permite conectar modelos de lenguaje con información real de una organización mediante herramientas especializadas, permitiendo consultar inventarios, ventas, ubicaciones y procesos internos usando lenguaje natural.

## Características

- IA local mediante Ollama.
- Tool Calling.
- Integración con PostgreSQL.
- Arquitectura modular.
- Consultas empresariales mediante lenguaje natural.

## Arquitectura

Usuario
↓
NEXA AI Agent
↓
Modelo LLM Local
↓
Tools
↓
Base de datos empresarial


## Caso demostrativo

Farmacia inteligente:

Ejemplos:

"¿Dónde está el ibuprofeno de 400 mg?"

"¿Qué productos necesitan reabastecimiento?"

"¿Qué lotes vencen próximamente?"
